# Weather App

DESCRIPTION<br>
A basic weather app made for Parcel OS and the Hack Club Crossroads program.<br>
just type in your city and it will tell you the temperature (in degrees Celsius), humidity, and it includes a short description of the weather conditions with a corresponding emoji to represent it
